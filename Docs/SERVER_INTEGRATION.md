# MOD 다운로드 서버 연결

프로젝트나 첨부 지시서에는 기존 서버 코드, API 주소, 인증 방식, API 명세가 없었습니다. 새로운 서버나 허구의 주소는 만들지 않았습니다.

현재 완성된 경로는 `로컬 ZIP → ModInstaller → 검증 → 설치 → 활성화 → ContentRegistry`입니다. 서버 연결점은 `IModCatalogClient`이며 실제 구현은 제공된 API에 맞춰 추가해야 합니다.

필요한 정보:

1. HTTPS 기본 URL, 목록·상세·다운로드 엔드포인트와 응답 JSON 예시.
2. 인증 방식, 토큰 보관·갱신 규칙. 비밀 키를 저장소에 커밋하지 않습니다.
3. 검색·페이지네이션·버전 필터·게임 버전 호환 규칙.
4. ZIP URL의 만료·리다이렉트 규칙, 파일 크기, SHA-256 또는 서명 검증 정보.
5. 오류·재시도·rate limit 정책과 배포 라이선스 표시 요구사항.

원격 구현도 내려받은 ZIP을 현재 설치 검증기로 전달해야 하며 검증을 우회하면 안 됩니다. 서버 기능이 작동한다고 표시하는 모의 UI는 넣지 않았습니다.
