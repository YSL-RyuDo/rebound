# RE:BOUND 1.1.0 — MOD Workshop

- 실버·골드·플래티넘·프리즘 증강. 최대 단계뿐 아니라 실제 능력치 상한까지 검사하여 무효 선택을 제외합니다.
- 카드의 실제 적용 전후 수치 표시, 복합 효과, 이전 선택창 중복 클릭 방지.
- 별도 MOD Workshop 씬: 기체·무기·몬스터·스테이지·증강·이펙트 폼 편집, 복제/추가, 저장/불러오기.
- PNG 가져오기와 이미지 연결, 이펙트 색·수명·입자 수·속도·크기 편집.
- 직선·파동·포물선·유도 탄환의 수치 편집과 공통 궤적 미리보기.
- 초안 테스트 플레이, 기존 MOD ZIP 가져오기, 배포 ZIP 내보내기. 기존 v1.0 MOD 호환.

`REBOUND.zip`을 풀고 `REBOUND.exe`를 실행한 뒤 **MOD WORKSHOP**을 선택합니다. Unity 메뉴는 **REBOUND → Open MOD Workshop**입니다. 제작 안내: `Docs/WORKSHOP_GUIDE.md`.

EditMode 11개 및 PlayMode 20개 통과. Windows 실행 파일에서 실제 UI 콜백·PNG·복합 증강·ZIP 설치·초안 전투·이펙트 적용을 검사했습니다. 수동 장시간 밸런스 검증은 남아 있습니다.

범위: 새 증강은 제공된 효과의 조합입니다. 임의 C# 실행, 자유 곡선 에디터, 애니메이션 시트, 원격 게시 서버는 포함하지 않습니다.

# RE:BOUND 1.0.0 (이전 기록)

Windows x64에서 실행하는 오리지널 중력 로그라이크 슈팅 게임입니다.

- A/D 이동, Space 상승, 실제 하강 에너지와 반동 공격.
- 자동 조준·치명타·다중 발사·관통, 4종 적, 시간별 웨이브와 3단계 보스.
- 경험치, 13종 기본 업그레이드, 중복 없는 3지선다.
- 메뉴·스토리·설정·키 매핑·일시정지·승패 결과·기록 저장.
- 로컬 ZIP MOD 관리 및 LIGHT FRAME / OVERCHARGE 샘플.
- 자체 생성 그래픽·이펙트·합성 효과음·4개 음악 루프.

`REBOUND-Windows-v1.0.0.zip`을 풀고 `REBOUND.exe`를 실행하세요. 실행 파일과 Data/DLL 폴더를 함께 유지해야 합니다. 샘플 MOD는 게임의 MOD MANAGER → INSTALL SAMPLES로 설치합니다.

Unity 2022.3.62f3에서 Edit Mode 5개, Play Mode 17개가 통과했으며 Windows 빌드와 스크립트 기반 실행 검증을 수행했습니다. 자세한 기록은 저장소의 `VALIDATION.md`를 참고하세요.

알려진 범위: UI와 스토리는 영문이며, 음악은 짧은 합성 루프입니다. 서버 API 정보가 없어 원격 MOD 다운로드는 미연결입니다. 실제 사용자 입력으로 5분 전체를 완료하는 수동 밸런스 테스트와 여러 PC 검증은 남아 있습니다.
